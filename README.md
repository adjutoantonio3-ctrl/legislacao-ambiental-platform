# Plataforma de Legislação Ambiental 🌽🏇  📛🔏

## Visão Geral

Uma plataforma inteligente e automatizada para monitoramento, divulgação e notificação de legislação ambiental em tempo real, abrangendo todas as esferas governamentais (federal, estadual, municipal) e autarquias.

## Funcionalidades

- **Monitoramento em Tempo Real**: Acompanhamento contínuo de fontes oficiais e verículos de notícias
- **Notificações Automáticas**: Email e rédes sociais com novas normas e regulamentações
- **Sistema de Assinatura Corporativa**: Assinatura anual especializada para pessoas jurídicas
- **Busca Avançada**: Filtros por jurisdição, data, tipo de norma e relevância
- **Integração Social**: Compartilhamento automático de alta relevância

## Tecnologias

- **Frontend**: Next.js + Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Edge Functions)
- **Hospedagem**: Vercel (autodeploy)
- **Pagamentos**: Stripe (assinatura anual)
- **Notificações**: Gmail + LinkedIn
- **Monitoramento**: IAs personalizadas + APIs de conteúdo
